# A Chemical Odyssey

Es un proyecto desarrollado por Juan Diego Fagua Ospina, David Santiago Rodríguez Aroca y Julián Felipe Sánchez García, estudiantes delInstituto Técnico Central (ETITC). Este surge tras identificar la problemática acerca de Química como una de las asignaturas 
más complejas para los estudiantes, lo que se refleja en los altos índices de reprobación académica de cada periodo. Que se traduce en una dificultad para comprender correctamente estas temáticas. Es así que proponemos una herramienta lúdica que busca transformar
el tiempo de ocio en la escuela en una oportunidad para reforzar habilidades académicas. A través de un recorrido por el colegio, y como alternativa al uso improductivo del celular, mediante el uso de Realidad Aumentada y cuestionarios (tests), los estudiantes pueden aprender los conceptos básicos de la materia y fortalecer sus competencias.

# Tutorial 

## Instalación
- Dirigite al repositorio GitHub 'Chemical_Odyssey' - https://github.com/JuanDFagua/Chemical_Odyssey (Este mismo) 
- Entra a la carpeta .\Aplicación y descarga el archivo 'chemical_odyssey.apk'
- Ejecuta el archivo desde tu celular y espera que se instale la aplicación
- Una vez instalada, abre la pp y comienza a aprender
